## Feature Overview & Description
How to Create an Order from the Swash Laundry Rider App

Welcome to the official Swash Laundry Software (SLS) tutorial series.

In this video, you'll learn how to create a new laundry order using the Swash Laundry Rider App. This feature allows riders to create customer orders directly from their mobile device, making the pickup process faster and more efficient.

In this video, you'll learn:
How to log in to the Rider App
How to create a new customer order
How to select laundry services
How to add garments and quantities
How to enter pickup and customer details
How to review and confirm the order
How to save the order successfully

The Swash Laundry Rider App enables riders to manage pickups, create orders, collect payments, update order statuses, and deliver a seamless customer experience.
