## Feature Overview & Description
The updated Order - Drop & Pick Up settings now allow separate delivery date offsets for per-weight and per-piece orders, improving control, flexibility, and order management for smoother operations and accuracy.
How It Works:
Go to Admin → Setup → Order - Drop & Pick Up.
You'll now see two separate fields for Delivery Date Offset – one for Per-Piece Orders and another for Per-Weight Orders.
