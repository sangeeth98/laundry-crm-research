## Feature Overview & Description
Introducing an enhanced feature in Store CRM for precise address management! 
On the customer creation screen, you can now select addresses using Google Maps and mandatorily capture geo-coordinates for accurate location tracking. 

Whether you're adding a new customer or updating an existing address, the process is seamless with fields like Google Map Address Search, 
Location 1, and Location 2, ensuring the exact Latitude and Longitude are saved for improved operational efficiency. The riders will also get the exact location on the MPOS with this capability.
