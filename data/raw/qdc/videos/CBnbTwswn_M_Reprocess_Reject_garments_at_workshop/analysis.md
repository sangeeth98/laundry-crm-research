## Feature Overview & Description
The workshop feature will include a rewash/reprocess system integrated into the screens. Each screen will feature a "Reprocess/Reject" button, dropdown menus for selecting the stage and return reason, and a comment box. 
A popup will appear to facilitate sending items back to the store. The rest of the screen will allow processing to continue through various stages. Only one garment can be returned at a time, and a rewash status table will be established for tracking purposes.
