## Feature Overview & Description
In this tutorial, you'll learn how to create a Per Piece order using the MPOS Rider App.

The video walks you through the complete order creation process, from selecting the customer to adding garments, choosing services, applying top-up services, and reviewing the order before submission.


Download the App - https://play.google.com/store/apps/details?id=com.quickdrycleaning.qdcpos
