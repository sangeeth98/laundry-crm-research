# Quick Dry Cleaning (QDC) Software

## Overview
Quick Dry Cleaning (QDC) is a specialized cloud POS and CRM software serving **5,000+ laundry businesses** across **22+ countries**.[^qdc-official]

## Core Features
- Touch POS for order creation (piece-rate and weight-rate).
- Barcode thermal garment tagging.
- SMS and WhatsApp customer updates.
- Prepaid package and customer wallet management.

## Strategic Gaps
- Windows legacy desktop design.
- No direct IoT machine hardware controllers.
- No visual AI photo stain defect tagging.
